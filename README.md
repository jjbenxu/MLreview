# MLreview

Interactive midterm review for Machine Learning for Business Analytics (BAN 6025).

Seven units, one per lecture deck: Introduction, Data Preparation, Model Building, Diagnostics, Binary Logistic Regression, Subset Selection, Model Assessment. Each unit has notes, a hands-on lab, flashcards and a quiz. There is also a practice midterm with worked answers, a random mock exam and a formula sheet.

Plain HTML, CSS and JavaScript with no build step. Open `index.html`, or serve the folder:

```bash
python3 -m http.server 4173
```

Content is summarized from Dr. Aric LaBarr's lecture decks and his course site, https://www.ariclabarr.com/machine-learning/.
